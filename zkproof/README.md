# EZKL zero-knowledge inference

Sakshi uses EZKL/Halo2 over the registered ONNX graph. Input visibility is `Hashed` (Poseidon): raw borrower features are private, while the Poseidon commitment is public. The model probability is a public output. The decision record stores that exact public commitment and quantized probability; the gateway bases APPROVE/REJECT on that probability, and the verifier checks that both match the signed record. The proof is bound to the registered model through its model hash and model-specific verification key.

Run `python3 zkproof/setup.py` after changing the model or registry. It compiles the circuit, creates local keys/SRS, and generates and verifies a smoke-test proof. Per-decision proofs are generated by `prove.py`. Keep proving keys, SRS, witness files, private inputs, and per-decision proofs local; they are ignored by git.

EZKL uses fixed-point quantization. The gateway checks the proof output against ONNX Runtime within a 0.002 tolerance and uses the proof's public quantized probability as the canonical decision value. The verifier checks the proof, proof-file hash, model hash, input commitment, and public probability against the signed record.
